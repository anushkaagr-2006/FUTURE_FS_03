## 🎯 About

Verdant Coffee Co. is a complete rebrand of Starbucks, reimagined as a sustainable, nature-inspired coffee company targeting the Chennai, India market. This project demonstrates full-stack web development capabilities, modern design principles, and AI-assisted content creation.

### Brand Identity

- **Name:** Verdant Coffee Co.
- **Tagline:** "Where Nature Meets Craft"
- **Colors:** Forest Green (#2C3D2F) & Terracotta (#B9855B)
- **Philosophy:** Sustainable luxury with urban garden aesthetics
- **Target Market:** Chennai, Tamil Nadu, India

---

## ✨ Features

### 🛍️ E-Commerce Functionality
- Product catalog with 6 unique signature drinks
- Shopping cart with add/remove and quantity management
- Real-time total calculation
- Persistent cart using localStorage

### 🔐 User Authentication
- Firebase Authentication (Email/Password)
- User profile creation and management
- Secure sign-in/sign-up flow

### 🎁 Rewards Program
- Welcome bonus: 250 points on sign-up
- Earn points: $1 spent = 10 points
- Redeem rewards:
  - 100 points → Free drink
  - 500 points → $10 discount
- Real-time points tracking stored in Firebase
- Points persist across sessions

### 📍 Location Finder
- 3 Chennai-based store locations
- Store details with images, hours, and addresses

### 🎨 Design Features
- Fully responsive design (mobile, tablet, desktop)
- Smooth animations and transitions
- AI-generated brand logo
- Professional product photography
- Custom Tailwind color palette

## 🌐 Deployment

### Deploy to Vercel

1. Push to GitHub
   ```bash
   git add .
   git commit -m "Initial commit"
   git push origin main
   ```

2. Import to Vercel
   - Go to [vercel.com](https://vercel.com)
   - Import your GitHub repository
   - Add environment variables
   - Deploy

3. Configure Firebase
   - Add Vercel domain to Firebase Authorized Domains
